**pi-webを試してみたいと考えているなら、挑戦してみましょう — きっと気に入ることでしょう。**

pi-web は [pi](https://pi.dev) — オープンソースのAIコーディングエージェント — ための美しい Web UI および PWA です。あらゆるブラウザ、あらゆるデバイスから、pi のセッションを閲覧・読み取り・続き作業を行うことができ、至るところに考え抜かれた機能が備わっています。

## この版の何が異なるのか？

このリポジトリは、upstream の pi-web インターフェースと共通機能を保持しながら、選択されたモデルがローカルまたは LAN 上で実行される場合のセッション保護方法を変更しています。

- **セッションごとにランタイムポリシーを選択。** プロバイダメタデータが明確な場合、ローカル/LAN エンドポイントを自動検出します。Local と Cloud は永続的な手動オーバーライドです。
- **コンテキスト失敗を早期に防止。** Local Mode は使用率 65% で compaction を行い、次のモデルリクエストの前にツール呼び出しの間にもう一度確認します。
- **サマリーを有界に保つ。** ローリングチェックポイントにより古いサマリーが無制限に増大することを避け、より厳しい予算で一度再試行し、compaction が意味のある進捗をもたらさない場合は安全に停止します。
- **保守的に復旧する。** コンテキストオーバーフロー、選択されたトランスポートの中断、reasoning 専用の早期停止は自動的に再開できますが、インシデントの重複排除と進捗を認識したサーキットブレーカーにより復旧ループを防ぎます。
- **ユーザーをコントロールする側に置く。** Force Compact は常に目に見える手動の救済パスであり、Cloud Mode は upstream のワークフローと制御を維持します。

実用的な結果はシンプルです：長時間のローカルモデルタスクは、倒れる前に compaction を行い、復旧が安全な場合一度だけ復旧し、そうでない場合はループする代わりにきれいに停止する、というものです。

**pi-web は2種類の人のために作られています：**

- 🧑‍💻 **開発者のために** — ターミナルに日々を費やしているが、モバイルからセッションの続きを作業したり、リモートサーバーへ引き継いだり、あらゆる場所から長時間実行中のタスクを監視したい人。
- ✨ **非開発者のために** — 単に美しい動作する AI アプリがほしい人。開いて、入力して、バイブ。ターミナルも SSH も、混乱もない。最もユーザーフレンドリーな AI ツールのようなものですが、モデル選択とオープンソースの自由が備わっています。

## なぜ pi-web なのか？

あなたはすでにターミナル上で pi に深く浸り、フローの中にいます。pi-web は、デスクを離れるときにもその勢いを維持してくれます：

- **どこからでも再開** — スマホ、タブレット、別のコンピュータからセッションを再開できます。SSH も Termius も不要 — ブラウザを開くだけです。
- **マルチセッションダッシュボード** — 1つのセッションで作業を開始しながら、もう1つのセッションのストリーミングを監視できます。プロジェクト間で検索し、ブランチで絞り込み、必要なものを素早く見つけます。
- **オープンソースの基盤** — pi は完全にオープンソースで、プロバイダ非依存です。単一のモデルやベンダーに閉じ込められることはありません。pi-web もオープンソースです。
- **安全なリモートアクセス** — 内蔵のトークン認証により、LAN や Tailscale に公開しても心配無用です。
- **作業の共有** — セッションを静的スナップショットやシークレットの GitHub Gist としてワンクリックでエクスポートできます。

## pi-web をあなたのパーソナルAIワークスペースとして 🏠

pi-web は PWA（Progressive Web App）なので、**ネイティブアプリのようにインストール**できます。デスクトップ、ラップトップ、スマホ、タブレットのいずれにも — アプリストアは不要です。デスクトップではブラウザの装飾なしに独自のウィンドウで開かれ、本当にデスクトップアプリのような見た目と感覚になります。

これは **あなた自身の Claude Cowork** と考えてください — あなたの機械上に住むパーソナルAIワークスペース — ただしオープンソースでモデル非依存です：

- **スタックはあなたのもの。** 任意のモデルを選び、いつでも切り替えることができます。ローカルモデルを実行すれば、あなたのデータは機械の外に決して出ません。
- **非技術者でも使える。** その人の機械に pi-web をセットアップし、使い方を一度示せば、あとは大丈夫。ご両親、パートナー、非技術の友人たち — ターミナルも SSH もなく、馴染みのあるチャットインターフェースだけです。
- **1つのセットアップ、多くのユーザー。** デスクトップにインストールして画面を共有するか、ホームネットワークに公開して家族が各自のデバイスで開くようにできます。

コーディング以上のものを求めますか？それが誰であるかを知り、あなたの機械上に住む専用の [パーソナルアシスタント](personal-assistant.md) へと変えてみてはどうでしょう — あなた自身の OpenClaw や Hermes のように。

> 💡 **プロのヒント：** Chrome/Edge（アドレスバーのインストールアイコンをクリック）または Safari（共有 → ドックに追加）から pi-web を PWA としてインストールしてください。ネイティブアプリと見分けがつかなくなります。

## pi-web でできること

| | |
|---|---|
| 📱 **PWA** | pi-web を Progressive Web App としてデスクトップ、スマホ、タブレットにインストールし、ネイティブのような感覚を実現します。 |
| 🔄 **セッションの継続** | どの会話も中断した場所からそのまま取りに戻せます — テキスト、画像、モデル切り替え、すべてブラウザから。 |
| 🆕 **新しいセッションを開始** | Web UI から直接、任意のプロジェクトパスに対して新しいセッションを作成できます。 |
| 📡 **ライブストリーミング** | pi のレスポンスを ~ms の遅延でリアルタイムにストリーミング表示できます。フォロームードで最新の箇所を追い続けます。 |
| 🌲 **ツリービュー** | pi のネイティブメッセージツリーをナビゲート — 会話の構造全体を見、任意のブランチへジャンプし、任意のポイントからフォークできます。 |
| 🔀 **セッションのフォーク** | メッセージや特定のツール呼び出しからセッションをフォーク — 場所を失うことなく異なる方向を探索できます。 |
| 🔍 **閲覧 & 検索** | プロジェクト間でセッションを絞り込み、名前で検索、ブランチをナビゲート — セッション履歴全体を一望できます。 |
| 🌿 **Git 統合** | 現在のブランチを確認し、セッションビューアから直接 GitHub PR を開けます。 |
| 📝 **スクラッチパッド** | アプリを切り替えずに、セッションの横にメモ、ToDo、一時的な考えを書き留めます。 |
| 💬 **アノテーション** | セッションの任意の部分にハイライトとコメントを追加 — コードレビュー、フィードバック、重要な瞬間のブックマークに最適です。 |
| 🎨 **テーマ & カスタマイズ** | ダークモードとライトモードを切り替え、UIを好みに調整 — pi-web を *あなた自身のもの* にします。 |
| 🌐 **マルチ言語** | 14の組み込み言語（English, Español, Français, Deutsch, 中文, 日本語, Bahasa Indonesia, Bahasa Melayu, Tiếng Việt, ไทย, Filipino, မြန်မာ, ភាសាខ្មែរ, ລາວ）。Settings から独自の言語を追加できます。 |
| 🐱 **ウェルネス & pomodoro** | 沢山のバイブコーディングは健康ではありません。猫の相棒と睡眠リマインダーを備えた内蔵 pomodoro タイマーでバランスを保ちます。 |
| 📤 **共有 & エクスポート** | JSONL をダウンロード、pi のネイティブ `pi.dev` ルックでレンダリングされた静的スナップショットをエクスポート、またはプライベートな GitHub Gist として共有 — すべてクライアントサイドでレンダリングされます。 |
| 🔔 **通知音** | セッションイベント用にカスタマイズ可能な通知チャイム — pi-web が別のタブにあっても最新状況を把握できます。 |
| ⌨️ **キーボードショートカット** | Vim スタイルのナビゲーション、クイックアクション — [完全なリファレンス →](keyboard-shortcuts.md) |
| 🤖 **パーソナルアシスタント** | pi-web をコンピュータ上に住むあなた自身の AI アシスタントに変える — OpenClaw や Hermes のように。[セットアップ →](personal-assistant.md) |
| 🗓️ **スケジュールと対話** | pi セッションから「シンガポール時間2時にスケジュールを追加…」といえば — `/skill:pi-web-schedule`。 |
| 📝 **メモ & 設定と対話** | 「これをメモに書き込む」（`/skill:pi-web-notes`）または「ダークモードに切り替える」（`/skill:pi-web-settings`）。 |
