# キーボードショートカット

これらのショートカットは、pi-web のローカルモデル版に適用されます。エディション固有のランタイム動作については、[ローカルモデル版の開発](../../docs/dev/local-llm-development.md)を参照してください。

## インデックスページ（`/`）

### ページスクロール（vim スタイル）

フォーカスがインプット、テキストエリア、または contenteditable 要素の**内側になく**場合、すべてのページで同じ vim スタイルのショートカットが動作します。

| ショートカット | 動作 |
|----------|--------|
| `j` | ページを下方向に 300px スクロール |
| `k` | ページを上方向に 300px スクロール |
| `g g` | ページの先頭にスクロール |
| `G`（Shift+G） | ページの末尾にスクロール |
| `Escape` | アクティブなインプットからフォーカスを外し、j/k ナビゲーションを有効にする |

### インデックスコマンド

| ショートカット | コンテキスト | 動作 |
|----------|---------|--------|
| `⌘K` / `Ctrl+K` | ページ全体 | 検索/セッションパレットを開く |
| `⌘⇧L` / `Ctrl+Shift+L` | ページ全体 | システムテーマ（ライト/ダーク）を切り替え |
| `Escape` | ページ全体 | パレット、メニュー、またはモーダルを閉じる |
| `Enter` | 新規セッションパスの入力欄 | 新規セッションを作成 |

> `⌘K` / `Ctrl+K` は Chrome の「アドレスバーにフォーカス」ショートカットでもあります。フォーカスがテキストインプット内にない限り、ブラウザがこれを割り込む可能性があります。

## セッション詳細ページ（`/session?id=...`）

### ページスクロール（vim スタイル）

フォーカスがインプット、テキストエリア、または contenteditable 要素の**内側になく**場合、インデックスページとセッションページの両方で動作します。

| ショートカット | 動作 |
|----------|--------|
| `j` | ページを下方向に 300px スクロール |
| `k` | ページを上方向に 300px スクロール |
| `g g` | ページの先頭にスクロール |
| `G`（Shift+G） | ページの末尾にスクロール |
| `I`（Shift+I） | チャット作成欄のテキストエリアにフォーカス |
| `Escape` | アクティブなインプットからフォーカスを外し、j/k ナビゲーションを有効にする |

### サイドバーとナビゲーション

| ショートカット | コンテキスト | 動作 |
|----------|---------|--------|
| `⌘B` / `Ctrl+B` | ページ全体 | サイドバーの表示を切り替え |
| `⌘K` / `Ctrl+K` | ページ全体 | セッションリストパレットを開く |
| `⌘T` / `Ctrl+T` | ページ全体 | 新規セッション |
| `⌘⇧L` / `Ctrl+Shift+L` | ページ全体 | システムテーマ（ライト/ダーク）を切り替え |
| `⌘⇧N` / `Ctrl+Shift+N` | ページ全体 | スクラッチパッド/メモサイドバーを切り替え |

> `⌘K` と `⌘T` もブラウザのショートカット（アドレスバーにフォーカス/新規タブ）です。フォーカスがテキストインプット内にない限り、ブラウザがこれらを割り込む可能性があります。

### チャット作成欄

| ショートカット | コンテキスト | 動作 |
|----------|---------|--------|
| `Enter` | チャットのテキストエリア | メッセージを送信 |
| `Shift+Enter` | チャットのテキストエリア | 改行を挿入 |
| `Shift+Tab` | チャットのテキストエリア | 次の思考レベルに切り替え（`off` → `minimal` → … → `xhigh` → `off`） |
| `Ctrl+I` / `Ctrl+L` | チャットのテキストエリア | モデル選択ポップアップを開く（入力で絞り込み、Enter で選択、フォーカスはテキストエリアに戻る） |

### エントリー表示の切り替え

| ショートカット | コンテキスト | 動作 |
|----------|---------|--------|
| `t` | フォーカスがインプット/テキストエリアの**外側**にある場合 | 思考の表示を切り替え |
| `o` | フォーカスがインプット/テキストエリアの**外側**にある場合 | ツールの表示を切り替え |
| `p` | フォーカスがインプット/テキストエリアの**外側**にある場合 | ツール出力を切り替え |

### パレット、メニュー、シートの表示

| ショートカット | コンテキスト | 動作 |
|----------|---------|--------|
| `Escape` | ページ全体 | 開いているパレット、メニュー、またはシートを閉じる |
| `⌘K` / `Ctrl+K` | ページ全体 | セッションリストパレットを開く |
| `ArrowUp` / `ArrowDown` | セッションリストパレット | セッションの結果をナビゲート |
| `Enter` | セッションリストパレット | 選択中（または最初）のセッションを開く |
| `ArrowUp` / `ArrowDown` | モデル選択ポップアップ | モデルリストをナビゲート |
| `Enter` | モデル選択ポップアップ | ハイライトされたモデルを選択 |
| `ArrowUp` / `ArrowDown` | フォークモーダル | メッセージをナビゲート |
| `Enter` | フォークモーダル | ハイライトされたメッセージからフォーク |
| `Tab` | フルスクリーンシート | シート内のフォーカスを切り替え |
| `Escape` | フルスクリーンシート | シートを閉じる |
