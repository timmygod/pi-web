# pi-web をパーソナルアシスタントとして

このワークフローはローカルモデル版でサポートされています。このエディションの
開発、同期、リリース方針については、
[ローカルモデル版の開発](../../docs/dev/local-llm-development.md) を参照してください。

pi-web はコーディングのためだけのものではありません — 自分のコンピュータに常駐する **パーソナル AI アシスタント** に変えることができます。まるで自分専用の OpenClaw や Hermes を持つようなものです。

## 仕組み

あなたのマシンに専用のフォルダを作成します — それがアシスタントの住処です。その中に `APPEND_SYSTEM.md` というファイルを入れ、アシスタントの正体、知っていること、動作の仕方を定義します。pi-web は、どのデバイスからでもアシスタントと会話するための美しいチャットインターフェースを提供します。

## ステップによる手順

### 1. アシスタントフォルダを作成

コンピュータ上のフォルダを選びます。例えば:

```
~/my-assistant/
```

### 2. アシスタントを定義

そのフォルダ内に `APPEND_SYSTEM.md` ファイルを作成します。ここでは、あなたのアシスタントが誰であるかを pi に伝えます:

```markdown
# My Personal Assistant

You are Jarvis, my personal AI assistant. You help me with:

- Daily planning and reminders
- Research and summarization
- Drafting emails and messages
- Brainstorming ideas
- Keeping track of things I mention

## About me

- I'm a software engineer who works remotely
- I have a cat named Pixel
- I prefer short, direct answers
- My timezone is PST

## Rules

- Be concise — I value brevity
- If you don't know something, say so
- Proactively remind me of things I asked you to track
```

pi は自動的にこの内容をすべての会話のシステムプロンプトに追記するので、アシスタントは常にあなたが誰で、どうサポートすべきかを知っています。

### 3. そのフォルダでセッションを開始

pi-web で、`~/my-assistant/`（またはあなたが命名したフォルダ）を指す新しいセッションを作成します。それだけです — パーソナルアシスタントと会話できます。

### 4. どこからでも利用

pi-web をスマホ、タブレット、ラップトップに PWA としてインストールします。アシスタントは常にそばにいます — いつでも、何を聞いても OK。

## アシスタントのアイデア

| ロール | APPEND_SYSTEM.md に書く内容 |
|---|---|
| 🧠 **ライフコーチ** | あなた goals、取り組んでいる習慣、ジャーナリングのプロンプト |
| 🏠 **ホームマネージャー** | 買い物リストのフォーマット、家族の好み、食事計画 |
| 💼 **ワークバッディ** | あなたの役割、現在のプロジェクト、会議メモのフォーマット、会社の文脈 |
| 📚 **学習パートナー** | 学んでいること、好みの説明スタイル、クイズモード |
| ✍️ **ライティングアシスタント** | あなたの文章スタイル、トーンの好み、よく使うフォーマット |

## より多くのコンテキストを追加

pi をより有用にするために、アシスタントフォルダに何を置いてくれても構いません:

- `notes/` — アシスタントが読める参照ファイル
- `context.md` — 生活や仕事に関する背景情報
- `projects.md` — 現在のプロジェクトとその状況

pi はフォルダ内のファイルを読めるので、与えるコンテキストが多いほど、より良くなります。

## pi-web に何かを頼む

`pi install npm:@timmygod/pi-web-local` の後、セッションから pi-web 自体に話しかけられます。
試してみてください:

- 「シンガポール時間午後2時に受信トレイを要約するスケジュールを追加して」
- 「私の pi-web のスケジュールを一覧にして」
- 「受信トレイのスケジュールを一時停止して」
- 「これをノートに書き留めて」
- 「pi-web をダークモードに切り替えて / 自動タイトルをオフにして」

同梱の **/skill:pi-web-schedule** スキルは、それを本物の pi-web スケジュール（`/schedules` で編集するのと同じもの）にします。各発火は **新しい** セッションを開始するので、指示は単体で成立してなければなりません — 「~/inbox の未読メールを要約する」は動作しますが、「これまでやっていたことを続けて」は動きません。

スケジュールは pi-web が起動している間のみ実行されます。
