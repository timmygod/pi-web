# ロードマップ

このロードマップは、pi-web のローカルモデル版に属します。アップストリームの機能は定期的に同期され、ローカルデプロイや信頼性の向上作業はこのラインで検証・リリースされます。[ローカルモデル版の開発](../../docs/dev/local-llm-development.md)を参照してください。

pi-web は2つのターゲットに向けて作られています。

- **開発者向け** — ターミナルで作業しているが、モバイルからセッションを続けたい、リモートサーバーへ引き継ぎたい、どこからでも長時間実行されるタスクの状態を確認したいという方。
- **非開発者向け** — 美しいAIアプリがただ動きさえすればよいという方。開いて、入力して、稼働させればいいだけ。ターミナルもSSHも不要、混乱もない。最もユーザーフレンドリーなAIツールのような感じですが、モデル選択とオープンソースの自由があります。

これから追加予定の機能は以下の通りです。

この版は、別のリリースラインでアップストリームの pi-web を追跡しています。アップストリームの機能は定期的にインポートされ、ローカルモデルの信頼性向上作業は優先的に行われ、ここではアップストリームのリリース履歴を変更せずに検証されます。

## ビジョン

長期的な目標: pi-web は **pi のインターフェース** になること — すべての人向けに。

- **非開発者** は、他のアプリと同じように開くだけです。モデルを選んで、入力する。それで終わり。コマンドラインは永遠に不要。
- **開発者** は深い統合を得られます — リモート引き継ぎ、マルチセッションダッシュボード、git 対応の閲覧、メッセージングボット。
- **すべての人** が、モデルの自由、オープンソースの透明性、そしてあらゆる場面で洗練を感じられるUIを得られます。
