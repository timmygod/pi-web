## តើមានអ្វីខុសគ្នាក្នុងកំណែនេះ?

ឃ្លាំងនេះរក្សាទុកចំណុចប្រទាក់ pi-web និងមុខងាររួមពី upstream ប៉ុន្តែផ្លាស់ប្តូររបៀបការពារសម័យកាលនៅពេលដែលគំរូដែលបានជ្រើសរើសដំណើរការក្នុងស្រុក ឬនៅលើ LAN របស់អ្នក។

- **ជ្រើសរើសគោលនយោបាយ runtime សម្រាប់សម័យកាលនីមួយៗ។** Auto រកឃើញចំណុចបញ្ចប់ក្នុងស្រុក/LAN នៅពេលដែលទិន្នន័យមេតាអ្នកផ្តល់សេវាមានភាពច្បាស់លាស់; Local និង Cloud គឺជាការជំនួសដោយដៃដែលមានលក្ខណៈអចិន្ត្រៃយ៍។
- **ការពារកំហុសបរិបទនៅដំណាក់កាលដំបូង។** Local Mode បង្រួមនៅពេលប្រើប្រាស់ 65% និងពិនិត្យម្តងទៀតរវាងការហៅឧបករណ៍ មុនពេលសំណើអ្នកផ្តល់សេវាបន្ទាប់។
- **រក្សាសេចក្តីសង្ខេបឱ្យមានដែនកំណត់។** ចំណុចត្រួតពិនិត្យប្តូរជំនាន់ជួយជៀសវាងការរីកលូតលាស់គ្មានទីបញ្ចប់នៃសេចក្តីសង្ខេបចាស់ ព្យាយាមម្តងទៀតដោយថវិកាតឹងរ៉ឹងជាងមុន និងឈប់ដោយសុវត្ថិភាពនៅពេលដែលការបង្រួមមិនផ្តល់នូវវឌ្ឍនភាពដែលមានន័យ។
- **ស្តារឡើងវិញដោយប្រុងប្រយ័ត្ន។** ការលើសបរិមាណបរិបទ ការរំខាននៃការដឹកជញ្ជូនដែលបានជ្រើសរើស និងការឈប់មុនកំណត់ដែលពាក់ព័ន្ធនឹងការសន្និដ្ឋានតែប៉ុណ្ណោះ អាចបន្តដោយស្វ័យប្រវត្តិ ប៉ុន្តែការលុបចោលព្រឹត្តិការណ៍ដែលស្ទួនគ្នា និងសៀគ្វីកាត់ផ្តាច់ដែលដឹងពីវឌ្ឍនភាព ជួយការពារវដ្តនៃការស្តារឡើងវិញ។
- **ទុកឱ្យអ្នកប្រើប្រាស់កាន់កាប់ការគ្រប់គ្រង។** Force Compact គឺជាផ្លូវសង្គ្រោះដោយដៃដែលមើលឃើញជានិច្ច ខណៈដែល Cloud Mode រក្សាទុកលំហូរការងារ និងការគ្រប់គ្រងពី upstream។

លទ្ធផលជាក់ស្តែងគឺសាមញ្ញ៖ កិច្ចការម៉ូដែលក្នុងស្រុកដែលមានរយៈពេលយូរគួរតែបង្រួមមុនពេលវាបរាជ័យ ស្តារឡើងវិញម្តងនៅពេលដែលការស្តារឡើងវិញមានសុវត្ថិភាព និងឈប់ដោយស្អាតជំនួសឱ្យការវិលជុំនៅពេលដែលវាមិនមានសុវត្ថិភាព។

**pi-web ត្រូវបានបង្កើតឡើងសម្រាប់មនុស្សពីរប្រភេទ៖**

- 🧑‍💻 **សម្រាប់អ្នកអភិវឌ្ឍន៍** — ដែលធ្វើការក្នុង terminal ប៉ុន្តែចង់បន្តវគ្គពីទូរស័ព្ទ ប្រគល់ទៅ server ពីចម្ងាយ ឬតាមដានកិច្ចការដែលដំណើរការយូរពីគ្រប់ទីកន្លែង។
- ✨ **សម្រាប់អ្នកមិនមែនជាអ្នកអភិវឌ្ឍន៍** — ដែលគ្រាន់តែចង់បានកម្មវិធី AI ដ៏ស្រស់ស្អាតដែលដំណើរការ។ បើកវា វាយអត្ថបទ សប្បាយ។ គ្មាន terminal គ្មាន SSH គ្មានភាពច្របូកច្របល់។ ដូចឧបករណ៍ AI ដែលងាយស្រួលប្រើបំផុត ប៉ុន្តែមានជម្រើសម៉ូដែល និងសេរីភាពប្រភពបើកចំហ។

## ហេតុអ្វី pi-web?

អ្នកកំពុងស្ថិតក្នុងលំហូរការងារជាមួយ pi ក្នុង terminal របស់អ្នកហើយ។ pi-web រក្សាសន្ទុះនោះឱ្យបន្តនៅពេលអ្នកចាកចេញពីតុរបស់អ្នក៖

- **បន្តពីគ្រប់ទីកន្លែង** — បន្តវគ្គពីទូរស័ព្ទ ថេប្លេត ឬកុំព្យូទ័រផ្សេងទៀតរបស់អ្នក។ គ្មាន SSH គ្មាន Termius — គ្រាន់តែបើក browser របស់អ្នក។
- **ផ្ទាំងគ្រប់គ្រងពហុវគ្គ** — ចាប់ផ្ដើមការងារក្នុងវគ្គមួយ ខណៈពេលមើលវគ្គផ្សេងទៀតដែលកំពុងដំណើរការ។ ស្វែងរកឆ្លងកាត់គម្រោង តម្រងតាម branch ស្វែងរកអ្វីដែលអ្នកត្រូវការបានលឿន។
- **មូលដ្ឋានប្រភពបើកចំហ** — pi គឺជាប្រភពបើកចំហពេញលេញ និងមិនជាប់ជាមួយអ្នកផ្ដល់សេវាណាមួយ។ អ្នកមិនត្រូវបានចាក់សោក្នុងម៉ូដែលឬអ្នកលក់តែមួយទេ។ pi-web ក៏ជាប្រភពបើកចំហដែរ។
- **ការចូលប្រើពីចម្ងាយដោយសុវត្ថិភាព** — មាន token auth ដែលភ្ជាប់មកជាមួយ ដូច្នេះអ្នកអាចបញ្ចេញវានៅលើ LAN ឬ Tailscale របស់អ្នកដោយគ្មានការព្រួយបារម្ភ។
- **ចែករំលែកការងាររបស់អ្នក** — នាំចេញវគ្គជារូបថតឋិតិវន្ត ឬ GitHub Gists សម្ងាត់តែមួយចុច។

## pi-web ជាកន្លែងធ្វើការ AI ផ្ទាល់ខ្លួនរបស់អ្នក 🏠

pi-web គឺជា PWA (កម្មវិធីបណ្ដាញជឿនលឿន) ដូច្នេះអ្នកអាច **ដំឡើងវាដូចកម្មវិធីធម្មជាតិ** នៅលើកុំព្យូទ័រលើតុ កុំព្យូទ័រយួរដៃ ទូរស័ព្ទ ឬថេប្លេតរបស់អ្នក — មិនត្រូវការ app store ទេ។ នៅលើកុំព្យូទ័រលើតុ វាបើកក្នុងបង្អួចផ្ទាល់ខ្លួនដោយគ្មាន browser chrome ដូច្នេះវាមើលទៅនិងមានអារម្មណ៍ដូចកម្មវិធីកុំព្យូទ័រពិតប្រាកដ។

គិតថាវាជា **Claude Cowork ផ្ទាល់ខ្លួនរបស់អ្នក** — កន្លែងធ្វើការ AI ផ្ទាល់ខ្លួនដែលរស់នៅលើម៉ាស៊ីនរបស់អ្នក — លើកលែងតែវាជាប្រភពបើកចំហ និងមិនជាប់ជាមួយម៉ូដែលណាមួយ៖

- **អ្នកជាម្ចាស់ប្រព័ន្ធ។** ជ្រើសរើសម៉ូដែលណាក៏បាន ប្ដូរពេលណាក៏បានតាមចិត្ត។ ដំណើរការម៉ូដែលក្នុងស្រុក ហើយទិន្នន័យរបស់អ្នកមិនដែលចាកចេញពីម៉ាស៊ីនរបស់អ្នកឡើយ។
- **មនុស្សដែលមិនមានជំនាញបច្ចេកទេសក៏អាចប្រើវាបាន។** ដំឡើង pi-web នៅលើម៉ាស៊ីនរបស់ពួកគេ បង្ហាញពួកគេពីរបៀបប្រើវាម្ដង ហើយពួកគេអាចប្រើបានភ្លាម។ ឪពុកម្ដាយរបស់អ្នក ដៃគូរបស់អ្នក មិត្តភក្តិដែលមិនមានជំនាញបច្ចេកទេស — គ្មាន terminal គ្មាន SSH គ្រាន់តែចំណុចប្រទាក់ជជែកដែលធ្លាប់ស្គាល់។
- **ដំឡើងម្ដង អ្នកប្រើប្រាស់ច្រើននាក់។** ដំឡើងវានៅលើកុំព្យូទ័រលើតុរបស់អ្នក ហើយចែករំលែកអេក្រង់របស់អ្នក ឬបញ្ចេញវានៅលើបណ្ដាញផ្ទះរបស់អ្នក ហើយឱ្យសមាជិកគ្រួសារបើកវានៅលើឧបករណ៍ផ្ទាល់ខ្លួនរបស់ពួកគេ។
