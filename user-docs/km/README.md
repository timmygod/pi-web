**កំពុងគិតថាចង់ព្យាយាមប្រើ pi-web? ធ្វើវាទៅ — អ្នកនឹងស្រឡាញ់វា។**

pi-web គឺជា UI របស់វេបសាយដែលមានក្តីស្រស់ស្អាត និងជា PWA សម្រាប់ [pi](https://pi.dev) — ប្រព័ន្ធដារសម្រាប់ដំណើរការកូដ AI ដែលមានបើកប្រព័ន្ធ (open-source)។ វាអនុញ្ញាតឱ្យអ្នកមើល អាន និងបន្តសំណេះសំណាលរបស់អ្នកពី pi ពីរាវត្រីណាមួយ លើឧបករណ៍ណាមួយ ដោយមានលក្ខណៈពិសេសដែលបានគិតគូរក្នុងជំហាននីមួយៗ។

## អ្វីដែលខុសគ្នាក្នុងជានិច្ចនេះ?

ក្បាសរ៉េបូ (repository) នេះរក្សាទុកនូវអ៊ីនទែសរបស់ pi-web ពីប្រភពដើម និងលក្ខណៈពិសេសដែលចែកចាយរួមគ្នា ប៉ុន្តែ
ប្តូរប្រភេទនៃការការពារសំណេះសំណាលនៅពេលដែលម៉ូដែលដែលបានជ្រើសរើសដំណើរការនៅក្នុងម៉ាស៊ីនផ្ទាល់ខ្លួន ឬនៅលើ
LAN របស់អ្នក។

- **ជ្រើសរើសគោលការណ៍ runtime ក្នុងកម្រិតសំណេះសំណាលមួយ។** Auto ប្រែក្លាយផ្ទាល់មកវិញសម្រាប់ endpoints ដែលជាក់លាក់នៅក្នុងម៉ាស៊ីនផ្ទាល់ខ្លួន/LAN ពេលដែល metadata របស់ provider មានភាពច្បាស់លាស់; Local និង Cloud គឺជាការប្តូរដែលជាក់លាក់រហូតដល់ពេលទូចដោយដៃ។
- **ការពារបញ្ហា context មុន។** Local Mode compacts នៅពេលប្រើប្រាស់ 65% និងពិនិត្យម្តងទៀតរវាងការហៅ tools មុនពេលស្នើសុំម៉ូដែលបន្ទាប់។
- **រក្សាសេចក្តីសង្ខេបឱ្យមានដែនកំណត់។** Rolling checkpoints ជួយការពារការធ្វើឱ្យសេចក្តីសង្ខេបចាស់នាំមកពង្រីកគ្មានដែនកំណត់ ព្យាយាមម្តងទៀតជាមួយ budget ដែលតឹងតែងបន្តិច ហើយឈប់ដោយសុវត្ថិភាពនៅពេល compaction មិនធ្វើបាននូវការបង្កើនជាក់លាក់។
- **ស្តារវិញដោយប្រុងប្រយ័ត្ន។** ពេល context overflow ការបិទការដឹកជញ្ជូនដែលបានជ្រើសរើស និងការឈប់ក្នុងការគិតមុនពេលអាចស្តារការបន្តដោយស្វ័យប្រវត្តិ ប៉ុន្តែការចំណុចព្រឹត្តិការណ៍ និង circuit breakers ដែលដឹងពីការបង្កើនការងារជួយការពារការងារស្តារដែលជំនួសគ្នា។
- **បណ្តុះអ្នកប្រើប្រាស់ឱ្យមានការគ្រប់គ្រង។** Force Compact គឺជានូវផ្លូវសង្គ្រោះដោយដៃដែលអាចមើលឃើញជានិច្ច រីឯ Cloud Mode រក្សាទុកនូវការងារធម្មតា និងការគ្រប់គ្រងពីប្រភពដើម។

លទ្ធផលជាក់ស្តែងគឺជារឿងងាយស្រួល: ការងារម៉ូដែលនៅក្នុងម៉ាស៊ីនផ្ទាល់ខ្លួនដែលមានរយៈពេលវែងគួរ compacts មុនពេលបរាជ័យ ស្តារម្តងនៅពេលដែលការស្តារមានសុវត្ថិភាព និងឈប់ដោយស្រួលជំនួសវិញនៃការងារដែលជំនួសគ្នាពេលដែលមិនមានសុវត្ថិភាព។

**pi-web ត្រូវបានបង្កើតឡើងសម្រាប់ប្រភេទមនុស្សពីរ:**

- 🧑‍💻 **សម្រាប់អ្នកអភិវឌ្ឍន៍** — ដែលរស់នៅក្នុង terminal ប៉ុន្តែចង់បន្តសំណេះសំណាលពីទូរស័ព្ទ ផ្ទេរទៅកាន់ឧបករណ៍មេរ៉ែកែរ ឬតាមដានការងារដែលដំណើរការយូរពីទីតាំងណាមួយ។
- ✨ **សម្រាប់អ្នកដែលមិនមែនជាអ្នកអភិវឌ្ឍន៍** — ដែលគ្រាន់តែចង់បានកម្មវិធី AI ដែលមានក្តីស្រស់ស្អាតហើយដំណើរការបាន។ បើកវា វាយសរសេរ vibe។ គ្មាន terminal គ្មាន SSH គ្មានភាពភៀសទស្សនិក។ ដូចជាបក្ខពលជាងកិច្ចព្រមព្រៀង AI ដែលងាយស្រួលប្រើប្រាស់បំផុត ប៉ុន្តែមានជម្រើសម៉ូដែល និងសេរីភាពបើកប្រព័ន្ធ។

## ហេតុអ្វី pi-web?

អ្នកស្ថិតក្នុងស្ថានភាព flow ជាមួយ pi ក្នុង terminal របស់អ្នកហើយ។ pi-web រក្សាទុកនូវកម្លាំងនោះនៅពេលអ្នកដំណើរចេញពីតុរបស់អ្នក:

- **បន្តពីទីតាំងណាមួយ** — បន្តសំណេះសំណាលពីទូរស័ព្ទ tablet ឬកុំព្យូទ័រផ្សេងទៀត។ គ្មាន SSH គ្មាន Termius — គ្រាន់តែបើករាវត្រីរបស់អ្នក។
- **បន្ទះគ្រប់គ្រងដែលមានសំណេះសំណាលច្រើន** — ចាប់ផ្តើមការងារក្នុងសំណេះសំណាលមួយខណៈកំពុងតាមដានសំណេះសំណាលផ្សេងទៀតដោយរលូន។ ស្វែងរកក្នុងគម្រោងផ្សេងៗ ប្រមូលផ្ដុំតាម branch រកអ្វីដែលអ្នកចាំបាច់យ៉ាងរហ័ស។
- **ប្រព័ន្ធនៃបើកប្រព័ន្ធ** — pi ជាបើកប្រព័ន្ធគ្មានទេហទ័ពដាច់ខាត និងមិនអាស្រ័យលើ provider ក្នុងរយៈពេលវែង។ អ្នកមិនត្រូវបានចាក់សោទៅម៉ូដែល ឬ vendor តែមួយទេ។ pi-web ក៏ជាបើកប្រព័ន្ធគ្មានទេហទ័ពដាច់ខាតដែរ។
- **ការប្រើប្រាស់ពីឆ្ងាយដោយសុវត្ថិភាព** — មានការផ្តល់អាទិភាព token ដែលត្រូវបានបង្កើតចូលដោយខ្លួនវា ដើម្បីអ្នកអាចបង្ហាញវាលើ LAN ឬ Tailscale របស់អ្នកដោយគ្មានការបារម្ភ។
- **ចែកចាយការងាររបស់អ្នក** — export សំណេះសំណាលជា snapshot ដែលមិនផ្លាស់ប្តូរ ឬជា Gist ដែលមានលេសស្រង់ក្នុង GitHub ជាមួយពណ៌មួយ។

## pi-web ជាទីធ្លា AI ផ្ទាល់ខ្លួនរបស់អ្នក 🏠

pi-web គឺជា PWA (Progressive Web App) ដូច្នេះអ្នកអាច **បញ្ជូនវាដូចកម្មវិធី native** ក្នុង desktop laptop ទូរស័ព្ទ ឬ tablet របស់អ្នក — គ្មាន app store ចាំបាច់។ នៅក្នុង desktop វាបើកនៅផ្សារបង្អួចផ្ទាល់ខ្លួនដោយគ្មានក្រមុខរបស់រាវត្រី ដូច្នេះវាងមើល និងមានអារម្មណ៍ដូចកម្មវិធី desktop ពិតប្រាកដ។

គិតពីវាដូចជា **Claude Cowork របស់អ្នកផ្ទាល់ខ្លួន** — ទីធ្លា AI ផ្ទាល់ខ្លួនដែលស្ថិតនៅលើម៉ាស៊ីនរបស់អ្នក — មិនដូចជាវាជាបើកប្រព័ន្ធគ្មានទេហទ័ពដាច់ខាត និងមិនអាស្រ័យលើម៉ូដែលទេ:

- **អ្នកជាម្ចាស់ stack ទាំងមូល។** ជ្រើសរើសម៉ូដែលណាមួយ ប្តូរនៅពេលណាក៏បាន។ ដំណើរការម៉ូដែលនៅក្នុងម៉ាស៊ីនផ្ទាល់ខ្លួនរបស់អ្នក និងទិន្នន័យរបស់អ្នកមិនទៅរកក្រៅម៉ាស៊ីនរបស់អ្នកទេ។
- **អ្នកដែលមិនមានជំនាងបច្ចេកទេសអាចប្រើវាបាន។** ដំឡើង pi-web នៅលើម៉ាស៊ីនរបស់ពួកគេ បង្ហាញឱ្យពួកគេដឹងពីរបៀបប្រើវាម្តង ហើយពួកគេក៏រួចរាល់ហើយ។ ឪពុកម្តាយរបស់អ្នក មិត្តភក្តិរបស់អ្នក មិត្តភក្តិដែលមិនជាប់លាប់បច្ចេកទេស — គ្មាន terminal គ្មាន SSH គ្រាន់តែមានផ្ទៃមុខ chat ដែលស្គាល់ផ្សៃ។
- **ការដំឡើងមួយ អ្នកប្រើប្រាស់ច្រើន។** បញ្ជូនវានៅលើ desktop របស់អ្នក និងចែកចាយផ្ទៃមុខរបស់អ្នក ឬបង្ហាញវាលើបណ្តាញផ្ទះរបស់អ្នក និងអនុញ្ញាតឱ្យសមាជិកក្រុងគ្រួសារបើកវានៅលើឧបករណ៍ផ្ទាល់ខ្លួនរបស់ពួកគេ។

ចង់បានច្រើនជាងកូដ? បំលែងវាជា [personal assistant](personal-assistant.md) ដែលបានបង្កើតជាក់លាក់ ដែលដឹងពីអត្តសញ្ញាណរបស់អ្នក និងស្ថិតនៅលើម៉ាស៊ីនរបស់អ្នក — ដូចជា OpenClaw ឬ Hermes របស់អ្នកផ្ទាល់ខ្លួន។

> 💡 **ការគួសឱ្យដឹង:** បញ្ជូន pi-web ជា PWA ពី Chrome/Edge (ទូច icon បញ្ជូននៅក្នុងរបារអាច) ឬ Safari (Share → Add to Dock)។ វាអាចប្រែក្លាយជាមិនអាចប្រែក្លាយជា native app ទេ។
