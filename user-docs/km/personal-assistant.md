# pi-web ជាអ្នកជំនួយផ្ទាល់ខ្លួនរបស់អ្នក

ដំណើរការនេះ ត្រូវបានគាំទ្រដោយកំណែ local-model។ សម្រាប់ការអភិវឌ្ឍ សំយោគ  និងគោលការណ៍បោះពុម្ពផ្សាយនៃកំណែនេះ សូមមើល
[Local-model edition development](../../docs/dev/local-llm-development.md)។

pi-web មិនមែនសម្រាប់ការបង្កើតកូដតែប៉ុណ្ណោះទេ — អ្នកអាចបំបែកវាទៅជាកំណែ **អ្នកជំនួយ AI ផ្ទាល់ខ្លួន** ដែលរស់នៅក្នុងកុំព្យូទ័ររបស់អ្នក ដូចជាមាន OpenClaw ឬ Hermes ផ្ទាល់ខ្លួនរបស់អ្នកសម្រាប់អ្នកផ្ទាល់។

## វាដំណើរការដូចម្តេច

អ្នកបង្កើតកម្រង់ឯកជនមួយក្នុងម៉ាស៊ីនរបស់អ្នក — នោះជានơiដែលអ្នកជំនួយរបស់អ្នករស់នៅ។ ក្នុងនោះ អ្នកដាក់ឯកសារ `APPEND_SYSTEM.md` ដែលកំណត់ថាអ្នកជំនួយរបស់អ្នកជាអ្នកណា វាដឹងអ្វី ហើយវាមានប្រតិកម្មយ៉ាងដូចម្តេច។ pi-web ផ្តល់ឱ្យអ្នកនូវប្រអប់កាណ្យប្រកបដោយសម្ភារៈសម្រាប់និយាយជាមួយវាពីគ្រប់ឧបករណ៍ណាក៏បាន។

## ជំហានតាមដំណាក់កាល

### 1. បង្កើតកម្រង់របស់អ្នកជំនួយ

ជ្រើសរើសកម្រង់មួយក្នុងកុំព្យូទ័ររបស់អ្នក។ អ្វីមួយដូចជា៖

```
~/my-assistant/
```

### 2. កំណត់អ្នកជំនួយរបស់អ្នក

បង្កើតឯកសារ `APPEND_SYSTEM.md` នៅក្នុងកម្រង់នោះ។ នេះជានơiដែលអ្នកប្រាប់ pi ថាអ្នកជំនួយរបស់អ្នកជាអ្នកណា៖

```markdown
# My Personal Assistant

You are Jarvis, my personal AI assistant. You help me with:

- Daily planning and reminders
- Research and summarization
- Drafting emails and messages
- Brainstorming ideas
- Keeping track of things I mention

## About me

- I'm a software engineer who works remotely
- I have a cat named Pixel
- I prefer short, direct answers
- My timezone is PST

## Rules

- Be concise — I value brevity
- If you don't know something, say so
- Proactively remind me of things I asked you to track
```

pi បន្ថែមឆ្នាំងនេះចូលទៅក្នុង system prompt នៃរាល់សម្ភាសន៍ដោយស្វ័យប្រវត្តិ ដូច្នេះអ្នកជំនួយរបស់អ្នកក្នុងនេះដឹងជាងអ្នកជាអ្នកណា និងរបៀបជួយប្រយោជន៍។

### 3. ចាប់ផ្តើមសំណែកក្នុងកម្រង់នោះ

ក្នុង pi-web បង្កើតសំណែកថ្មីមួយ ដែលបញ្ជាក់ទៅ `~/my-assistant/` (ឬណាមួយដែលអ្នកបានឈ្មោះវា)។ នោះជានេះ — អ្នកកំពុងនិយាយជាមួយអ្នកជំនួយផ្ទាល់ខ្លួនរបស់អ្នក។

### 4. ប្រើវាពីគ្រប់ទីកន្លែង

ដំឡើង pi-web ជា PWA នៅលើទូរស័ព្ទ ថេប៊្លេ ឬកុំព្យូទ័រក្រឡតារារបស់អ្នក។ អ្នកជំនួយរបស់អ្នកតែងតែនៅទីនោះ — ត្រួបត្រួតអ្វីក៏បាន គ្រប់ពេល។

## បន្ថែមបរិបទបន្ថែម

អ្នកអាចដាក់អ្វីក៏បានក្នុងកម្រង់អ្នកជំនួយរបស់អ្នកដែលជួយ pi ឱ្យមានប្រយោជន៍ច្រើនជាងមុន៖

- `notes/` — ឯកសារឯករាជ្យដែលអ្នកជំនួយរបស់អ្នកអាចអាន
- `context.md` — ព័ត៌មានផ្នែកផ្ទៃក្នុងអំពីជីវិត ឬការងាររបស់អ្នក
- `projects.md` — គម្រោងបច្ចុប្បន្ន និងស្ថានភាពរបស់វា

pi អាចអានឯកសារក្នុងកម្រង់ ដូច្នេះបរិបទដែលអ្នកផ្តល់វាបានច្រើន វាកាន់តែប្រសើរ។

## សុំ pi-web ធ្វើកិច្ចការ

បន្ទាប់ពី `pi install npm:@timmygod/pi-web-local` សំណែកអាចនិយាយជាមួយ pi-web ខ្លួនឯងបាន។
ព្យាយាម៖

- "បន្ថែមកាលវិភាគនៅម៉ោង 2 យប់ (ពេលវេលាសិង្ហបុរី) ដើម្បីសរុបប្រអប់ជាសម្រេចរបស់ខ្ញុំ"
- "រាយបញ្ជីកាលវិភាគ pi-web របស់ខ្ញុំ"
- "ផ្អាកកាលវិភាគប្រអប់ជាសម្រេច"
- "សរសេរនេះក្នុង notes"
- "ប្ដូរ pi-web ទៅគម្របទងស្រួច / បិទ auto-title"

កម្មវិធី **/skill:pi-web-schedule** ដែលក្នុងបង្កើតត្រូវបានបំបែកទៅជាកាលវិភាគ pi-web ពិតប្រាកដមួយ (ដូចទៅនឹងដែលអ្នកកែតម្រង់នៅ `/schedules`)។ រាល់ការបង្ហោះនឹងចាប់ផ្តើមសំណែក **ថ្មី** មួយ ដូច្នេះការណែនាំត្រូវតែដំណើរការដោយឯករាជ្យ — "សរុបអ៊ីម៉ែលដែលមិនទាន់បានអានក្នុង ~/inbox" ដំណើរការ; "បន្តអ្វីដែលយើងបានធ្វើ" មិនដំណើរការទេ។

កាលវិភាគដំណើរការតែពេល pi-web កំពុងដំណើរការប៉ុណ្ណោះ។
