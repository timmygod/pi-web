# Roadmap

ផែនការដើមឡាន់នេះគឺស្ថិតក្នុងកំណែ local-model របស់ pi-web។ មុខងារ upstream ត្រូវបានធ្វើសមកាលកម្មជាទៀងទាត់ ខណៈដែលការងារប្រតិបត្តិការ និងភាពអាសន្នរបស់កម្មវិធីដែលដាក់ប្រើក្នុងកម្មសិទ្ធិផ្ទាល់ ត្រូវបានផ្ទៀងផ្ទាត់ និងបញ្ចេញទៅក្នុងខ្សែផលិតផលនេះ; សូមមើល [ការអភិវឌ្ឍន៍កំណែ local-model](../../docs/dev/local-llm-development.md)។

pi-web ត្រូវបានសាងសង់ឡើងសម្រាប់សមុទ្រសមាជិកពីរ៖

- **សម្រាប់អ្នកអភិវឌ្ឍន៍** — ដែលរស់នៅក្នុង terminal ប៉ុន្តែចង់បន្ត session ពីទូរសព្ទ បញ្ជូនទៅកម្មវិធីឈប់សកម្ម (remote server) ឬតាមដេញសកម្មភាពដែលប្រតិបត្តិការយូរពីទីណាក៏បាន។
- **សម្រាប់អ្នកមិនមែនជាអ្នកអភិវឌ្ឍន៍** — ដែលគ្រាន់តែចង់មានកម្មវិធី AI ដែលគួរឱ្យទាក់ទាញ និងដំណើរការល្អ។ បើកវា បញ្ចូលអក្សរ ហើយមានអារម្មណ៍ល្អ។ គ្មាន terminal គ្មាន SSH គ្មានភាពចម្រមុយ។ ដូចជាកម្មវិធី AI ដែលងាយប្រើប្រាស់បំផុត ប៉ុន្តែមានការជ្រើសរើស model និងសេរីភាព open-source។

នេះជារឿងដែលកំពុងមកដល់។

កំណែនេះតាមបណ្តាញ pi-web upstream ក្នុងខ្សែផលិតផលដាច់ដោយឡែក។ មុខងារ upstream ត្រូវបាននាំចូលជាទៀងទាត់; ការងារភាពអាសន្នរបស់ local-model ត្រូវបានចូលរួម និងផ្ទៀងផ្ទាត់នៅទីនេះ ដោយមិនផ្លាស់ប្តូរប្រវត្តិបញ្ចេញផលិតផល upstream ទេ។

## មេរៀន

គោលដៅរយៈពេលវែង: pi-web គួរតែជា **ផ្ទៃក្រៅសម្រាប់ pi** — សម្រាប់គ្រប់នរណា។

- **អ្នកមិនមែនជាអ្នកអភិវឌ្ឍន៍** បើកវាដូចកម្មវិធីផ្សេង។ ជ្រើសរើស model។ បញ្ចូលអក្សរ។ រួចរាល់។ គ្មាន command line ទាល់តែសោះ។
- **អ្នកអភិវឌ្ឍន៍** ទទួលបានការបញ្ចូលគ្នាជ្រៅ — ការបញ្ជូនទៅ remote កម្មវិធីផ្ទាល់ (handoff) ក្តារបញ្ជា multi-session ការមើលដែលដឹងពី git និង messaging bots។
- **គ្រប់នរណា** ទទួលបានសេរីភាព model ភាពស្មោះត្រង់ open-source និង UI ដែលមានអារម្មណ៍គិតគូរគ្រប់ជំហាន។
