# ປັດຖະໜັງສີຫຼັດ

ຄວັນສັອດເຫຼົ່ານີ້ນຳໃຊ້ກັບຮາກສະບັບ local-model ຂອງ pi-web. ລະບົບການເຮັດວຽກຂອງ runtime ຕາມຮາກສະບັບ ຖືກອະທິບາຍໄວ້ໃນ [Local-model edition development](../../docs/dev/local-llm-development.md).

## ໜ້າ Index (`/`)

### ແລ່ນຜ່ານໜ້າ (ແບບ vim)

ຄວັນສັອດແບບ vim ຕົ້ນກັນນີ້ໃຊ້ໄດ້ທຸກໜ້າ ເມື່ອ focus **ບໍ່** ມືອຢູ່ໃນ input, textarea ຫຼື ຢ່າງ contenteditable.

| ຄວັນສັອດ | ກິດຈະກຳ |
|----------|--------|
| `j` | ແລ່ນລົງ 300px |
| `k` | ແລ່ນຂຶ້ນ 300px |
| `g g` | ແລ່ນໄປຫາເທິງສູງສຸດຂອງໜ້າ |
| `G` (Shift+G) | ແລ່ນໄປຫາຕ່ຳສຸດຂອງໜ້າ |
| `Escape` | ເຮັດໃຫ້ active input ແຈກອອກ ເພື່ອໃຫ້ການນຳທາງ j/k ໃຊ້ໄດ້ |

### ລະຫັດທີ່ຮຽກໃຊ້ໃນໜ້າ Index

| ຄວັນສັອດ | ສະຖານະການ | ກິດຈະກຳ |
|----------|---------|--------|
| `⌘K` / `Ctrl+K` | ລະດັບໜ້າ | ເປີດຊ່ອງຄົ້ນຫາ/sessions palette |
| `⌘⇧L` / `Ctrl+Shift+L` | ລະດັບໜ້າ | ແທນຮູບແບບລະບົບ (ແສງ/ມືດ) |
| `Escape` | ລະດັບໜ້າ | ປິດ palette, ເມນູ ຫຼື modal |
| `Enter` | ແປ້ນ input ສຳລັບສິ່ງແປ້ນ session ໃໝ່ | ເຮັດ session ໃໝ່ |

> `⌘K` / `Ctrl+K` ຍັງເປັນຄວັນສັອດ "focus ແປ້ນທີ່ຢູ່ (address bar)" ຂອງ Chrome ແລະຊ່າງອີກ. ໂປຣແກຣມແບຣວເຊີອາດຈະຕັດລັກແລ້ວຖ້າ focus ບໍ່ຢູ່ໃນໃບຂຽນ.

## ໜ້າລາຍລະອຽດ Session (`/session?id=...`)

### ແລ່ນຜ່ານໜ້າ (ແບບ vim)

ຄວັນສັອດເຫຼົ່ານີ້ໃຊ້ໄດ້ທັງໃນໜ້າ index ແລະ ໜ້າ session ເມື່ອ focus **ບໍ່** ມືອຢູ່ໃນ input, textarea ຫຼື ຢ່າງ contenteditable.

| ຄວັນສັອດ | ກິດຈະກຳ |
|----------|--------|
| `j` | ແລ່ນລົງ 300px |
| `k` | ແລ່ນຂຶ້ນ 300px |
| `g g` | ແລ່ນໄປຫາເທິງສູງສຸດຂອງໜ້າ |
| `G` (Shift+G) | ແລ່ນໄປຫາຕ່ຳສຸດຂອງໜ້າ |
| `I` (Shift+I) | Focus ໄປທີ່ textarea ສຳລັບຂຽນຂໍ້ຄວາມ chat |
| `Escape` | ເຮັດໃຫ້ active input ແຈກອອກ ເພື່ອໃຫ້ການນຳທາງ j/k ໃຊ້ໄດ້ |

### ຊ່ອງຂ້າງ & ນຳທາງ

| ຄວັນສັອດ | ສະຖານະການ | ກິດຈະກຳ |
|----------|---------|--------|
| `⌘B` / `Ctrl+B` | ລະດັບໜ້າ | ແທນສະແດງ/ເຊັນສະດວກຂອງໂຈ້ນຂ້າງ |
| `⌘K` / `Ctrl+K` | ລະດັບໜ້າ | ເປີດຊ່ອງລາຍການ session |
| `⌘T` / `Ctrl+T` | ລະດັບໜ້າ | ເຮັດ session ໃໝ່ |
| `⌘⇧L` / `Ctrl+Shift+L` | ລະດັບໜ້າ | ແທນຮູບແບບລະບົບ (ແສງ/ມືດ) |
| `⌘⇧N` / `Ctrl+Shift+N` | ລະດັບໜ້າ | ແທນຮູບແບບ scratchpad / ໂຈ້ນຂ້າງຂອງໂຈດປ້ອນໂຕ |

> `⌘K` ແລະ `⌘T` ຍັງເປັນຄວັນສັອດຂອງແບຣວເຊີ (focus ແປ້ນທີ່ຢູ່ / ເຕັບໃໝ່). ໂປຣແກຣມແບຣວເຊີອາດຈະຕັດລັກແລ້ວຖ້າ focus ບໍ່ຢູ່ໃນໃບຂຽນ.

### ຕຸກເຕີບຂຽນຂໍ້ຄວາມ Chat

| ຄວັນສັອດ | ສະຖານະການ | ກິດຈະກຳ |
|----------|---------|--------|
| `Enter` | Chat textarea | ເກາຂໍ້ຄວາມອອກ |
| `Shift+Enter` | Chat textarea | ເອີ້ນສັກຂຶ້ນ |
| `Shift+Tab` | Chat textarea | ເພີ່ມ/ຫຼຸດລະດັບຄິດ (thinking) |
| `Ctrl+I` / `Ctrl+L` | Chat textarea | ເປີດຂອງທຣີແປຊັນ (type to filter, Enter to select, focus ກັບຄືນສູ່ textarea) |

### ສະແດງ/ເຊັນສະດວກຂອງເຂດຂໍ້ຄວາມ

| ຄວັນສັອດ | ສະຖານະການ | ກິດຈະກຳ |
|----------|---------|--------|
| `t` | ເມື່ອ focus **ບໍ່** ຢູ່ໃນ input/textarea | ແທນສະແດງ thinking |
| `o` | ເມື່ອ focus **ບໍ່** ຢູ່ໃນ input/textarea | ແທນສະແດງ tools |
| `p` | ເມື່ອ focus **ບໍ່** ຢູ່ໃນ input/textarea | ແທນສະແດງ tool outputs |

### ຊ່ອງແຊມ, ເມນູ & ຮ່ອງແຊມ (sheets)

| ຄວັນສັອດ | ສະຖານະການ | ກິດຈະກຳ |
|----------|---------|--------|
| `Escape` | ລະດັບໜ້າ | ປິດຮ່ອງແຊມ, ເມນູ ຫຼື ຮ່ອງແຊມ (sheet) ທີ່ເປີດຢູ່ |
| `⌘K` / `Ctrl+K` | ລະດັບໜ້າ | ເປີດຮ່ອງແຊມລາຍການ session |
| `ArrowUp` / `ArrowDown` | ຮ່ອງແຊມລາຍການ session | ນຳທາງຜົນລັບ session |
| `Enter` | ຮ່ອງແຊມລາຍການ session | ເປີດ session ທີ່ເລືອກ (ຫຼື ຄຽງທຳອິດ) |
| `ArrowUp` / `ArrowDown` | ຮ່ອງແຊມແປຊັນ model | ນຳທາງລາຍການ model |
| `Enter` | ຮ່ອງແຊມແປຊັນ model | ເລືອກ model ທີ່ປິດ |
| `ArrowUp` / `ArrowDown` | ຮ່ອງແຊມ Fork modal | ນຳທາງຂໍ້ຄວາມ |
| `Enter` | ຮ່ອງແຊມ Fork modal | Fork ຈາກຂໍ້ຄວາມທີ່ປິດ |
| `Tab` | ຮ່ອງແຊມຮູບແບບຕັ້ງດ້າງ (full-screen sheet) | ບຸນ focus ໃນຮ່ອງແຊມ |
| `Escape` | ຮ່ອງແຊມຮູບແບບຕັ້ງດ້າງ (full-screen sheet) | ປິດຮ່ອງແຊມ |
