# pi-web ເປັນໄຮ້ສອນສ່ວນຕົວຂອງທ່ານ

ໂປຣເຊດເຊີນີ້ຖືກຕັ້ງໜຸງຈາກຊຸດ local-model. ສຳລັບນະໂຍບາຍການພັດທະນາ, ການເພື່ອດຶງວັດແລະການປ່ອຍຂອງຊຸດດັ່ງກ່າວ, ຈົ່ງເບິ່ງ
[ການພັດທະນາ local-model edition](../../docs/dev/local-llm-development.md).

pi-web ບໍ່ແມ່ນສຳລັບການຂຽນ code ກໍ່ພຽງ — ທ່ານສາມາດປ່ຽນມັນໃຫ້ເປັນ **ໄຮ້ສອນ AI ສ່ວນຕົວ** ທີ່ຢູ່ເທິງຄອມພິວເຕີຂອງທ່ານ, ຄ້າຍຄືມີ OpenClaw ຫຼື Hermes ຂອງທ່ານເອງ.

## ນັ້ນເຮັດວຽກແນວໃດ

ທ່ານສ້າງໂຟເດີສຳເນາສະເພາະເທິງເຄື່ອງຂອງທ່ານ — ນັ້ນແມ່ນບ່ອນທີ່ໄຮ້ສອນຂອງທ່ານຢູ່. ໃນນັ້ນ, ທ່ານວາງໄຟລ໌ `APPEND_SYSTEM.md` ທີ່ນິຍາມວ່າໄຮ້ສອນຂອງທ່ານແມ່ນໃຜ, ມັນຮູ້ແວດຫຍັງ, ແລະມັນເພີ່ນພ້ອມແນວໃດ. pi-web ນຳໃຫ້ທ່ານໂຄດຫັດ (interface) ທີ່ມີຄວາມງາມເພື່ອແລະເວົ້າກັບມັນຈາກເຄື່ອງໃດກໍ່ໄດ້.

## ຕາມຂັ້ນຕອນ

### 1. ສ້າງໂຟເດີໄຮ້ສອນຂອງທ່ານ

ເລືອກໂຟເດີເທິງຄອມພິວເຕີຂອງທ່ານ. ຄ້າຍຄື:

```
~/my-assistant/
```

### 2. ນິຍາມໄຮ້ສອນຂອງທ່ານ

ສ້າງໄຟລ໌ `APPEND_SYSTEM.md` ພາຍໃນໂຟເດີນັ້ນ. ນີ້ແມ່ນບ່ອນທີ່ທ່ານບອກ pi ວ່າໄຮ້ສອນຂອງທ່ານແມ່ນໃຜ:

```markdown
# My Personal Assistant

You are Jarvis, my personal AI assistant. You help me with:

- Daily planning and reminders
- Research and summarization
- Drafting emails and messages
- Brainstorming ideas
- Keeping track of things I mention

## About me

- I'm a software engineer who works remotely
- I have a cat named Pixel
- I prefer short, direct answers
- My timezone is PST

## Rules

- Be concise — I value brevity
- If you don't know something, say so
- Proactively remind me of things I asked you to track
```

pi ຈະເພີ່ມໂຕເຂົ້າໃສ່ system prompt ຂອງແຕ່ລະການເລົ່າເຖິງໄປ, ດັ່ງນັ້ນໄຮ້ສອນຂອງທ່ານຈຶ່ງຮູ້ວ່າທ່ານແມ່ນໃຜ ແລະ ຈະຊ່ວຍແນວໃດ.

### 3. ເລີ່ມ session ໃນໂຟເດີນັ້ນ

ໃນ pi-web, ສ້າງ session ໃໝ່ຊີ້ໄປທີ່ `~/my-assistant/` (ຫຼືຊື່ທ່ານຖ້າຫາກທ່ານໃຫ້ຊື່). ນັ້ນແມ່ນແລ້ວ — ທ່ານກຳລັງເວົ້າກັບໄຮ້ສອນສ່ວນຕົວຂອງທ່ານ.

### 4. ໃຊ້ມັນຈາກທຸກສະຖານທີ່

ຕິດຕັ້ງ pi-web ເປັນ PWA ໃສ່ໂທລະສັບ, ແທັບເລັດ ຫຼື ແລັບທອບຂອງທ່ານ. ໄຮ້ສອນຂອງທ່ານຢູ່ນັ້ນສະເໝີ — ຖາມຫຍັງກໍ່ໄດ້, ຕາມທຸກຄັບເວລາ.

## ແນວຄຸມໄຂສ່ວນສ່ວນໄຮ້ສອນຂອງທ່ານ

| ບົດບາດ | ວາງຫຍັງໃນ APPEND_SYSTEM.md |
|---|---|
| 🧠 **ຜູ້ຄຸມແຮງແລະພັກ** | ກົມຈົງ, ຝັກຖິ່ນທ່ານກຳລັງພັດທະນາ, ສຳລັບເລີ່ມຄວາມຄິດບັນທຶກ |
| 🏠 **ຜູ້ຄຸມບ້ານ** | ຮູບແບບອະໄລດອັງເພັງ, ຄວາມຮັກຄີຂອງສະມາຊິກຄອບຄົວ, ການສືບຕໍ່ຕຸກຂອງອາຫານ |
| 💼 **ຄູ່ເພື່ອນງານ** | ວຽກຂອງທ່ານ, ໂປຣເຈັກແລະຕິກຄວາມຄິດປັດຈຸບັນ, ໂຄດທົດແບບປະຕິທັດ, ສັງຄອມບຶດບຸກຂອງບໍລິສັດ |
| 📚 **ຄູ່ຮຽນ** | ສິ່ງທ່ານກຳລັງຮຽນ, ໂຄດທົດແບບອະສາມາດທີ່ດີ, ໂໝດທົດສອບ |
| ✍️ **ໄຮ້ສອນຝຶກຂຽນ** | ຮູບແບບຂຽນຂອງທ່ານ, ກົນໄຈແຫ່ງແບບອະສາມາດ, ໂຄດທົດແບບທົ່ວໄປທ່ານໃຊ້ |

## ເພີ່ມຄວາມເຫັນເພີ່ມເຕີມ

ທ່ານສາມາດວາງສິ່ງທີ່ຊ່ວຍ pi ໃຫ້ມີປະໂຫຍດຫຼາຍຂຶ້ນພາຍໃນໂຟເດີໄຮ້ສອນຂອງທ່ານ:

- `notes/` — ໄຟລ໌ແລະອ້າງອີງທີ່ໄຮ້ສອນຂອງທ່ານສາມາດອ່ານໄດ້
- `context.md` — ຄວາມຮູ້ພື້ນຖານກ່ຽວກັບຊີວິດ ຫຼື ແລະ ເຮັດວຽກຂອງທ່ານ
- `projects.md` — ໂປຣເຈັກປັດຈຸບັນ ແລະ ສະພາບຂອງພວກມັນ

pi ສາມາດອ່ານໄຟລ໌ໃນໂຟເດີ, ດັ່ງນັ້ນທຸກຄົນທີ່ທ່ານໃຫ້ມັນ, ມັນຈະດີຂຶ້ນ.

## ຢ້າມ pi-web ໃຫ້ເຮັດສິ່ງໄດ້

ຫຼັງຈາກ `pi install npm:@timmygod/pi-web-local`, ທຸກ session ສາມາດເວົ້າກັບ pi-web ໄດ້.
ລອງ:

- “ເພີ່ມຫົວຂໍ້ສະເພາະຕອນ 2 ໂມງເວລາສິງກະໂປ ເພື່ອສະຫຼຸບອີເມວ໌ຂອງຂ້ອຍ”
- “ຈັດຕາມຫົວຂໍ້ຂອງຂ້ອຍ”
- “ຢຸດເຊົ້າຫົວຂໍ້ inbox”
- “ຂຽນນີ້ລົງໃສ່ບັນທຶກ”
- “ປ່ຽນ pi-web ໄປໃສ່ໂໝດມືດ / ຢຸດ auto-title”

**/skill:pi-web-schedule** ທີ່ມາຢ່າງແລ້ວປ່ຽນມັນເປັນຫົວຂໍ້ pi-web ສຳເນາ (ດຽວກັນກັບທີ່ທ່ານແກ້ໄຂຢູ່ `/schedules`). ທຸກຄັບການເລີ່ມຈະເລີ່ມ session ໃໝ່, ດັ່ງນັ້ນຄຳສັບຈໍາລອງຕ້ອງເຂົ້າໃຈໂດຍຕົນເອງ — “ສະຫຼຸບໄພແລະອ່ານໃນ ~/inbox” ໃຊ້ໄດ້; “ສືບຕໍ່ຫຍັງທີ່ເຮົາກຳລັງເຮັດ” ບໍ່ໄດ້.

ຫົວຂໍ້ຈະລ້າງພຽງເທົ່າທີ່ pi-web ກຳລັງລ້າງ.
