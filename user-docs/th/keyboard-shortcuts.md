# คีย์ลัดบนแป้นพิมพ์

คีย์ลัดเหล่านี้ใช้กับรุ่น local-model ของ pi-web พฤติกรรมขณะทำงานที่เฉพาะของรุ่นนี้จัดทำเอกสารไว้ใน [Local-model edition development](../../docs/dev/local-llm-development.md)

## หน้าอินเด็กซ์ (`/`)

### เลื่อนหน้า (สไตล์ vim)

คีย์ลัดสไตล์ vim ชุดเดียวกันทำงานได้บนทุกหน้าเมื่อโฟกัส **ไม่** อยู่ในช่อง input, textarea หรือ contenteditable element

| คีย์ลัด | การกระทำ |
|----------|--------|
| `j` | เลื่อนลง 300px |
| `k` | เลื่อนขึ้น 300px |
| `g g` | เลื่อนขึ้นไปที่ด้านบนของหน้า |
| `G` (Shift+G) | เลื่อนลงไปด้านล่างของหน้า |
| `Escape` | ปลดโฟกัสจากช่อง input ที่กำลังใช้งาน เพื่อให้อนุญาตการเลื่อนด้วย j/k ทำงานได้ |

### คำสั่งหน้าอินเด็กซ์

| คีย์ลัด | บริบท | การกระทำ |
|----------|---------|--------|
| `⌘K` / `Ctrl+K` | ระดับหน้า | เปิดพาเลตค้นหา/เซสชัน |
| `⌘⇧L` / `Ctrl+Shift+L` | ระดับหน้า |สลับธีมระบบ (สว่าง/มืด) |
| `Escape` | ระดับหน้า | ปิดพาเลต เมนู หรือโมดัล |
| `Enter` | ช่อง input เส้นทางของเซสชันใหม่ | สร้างเซสชันใหม่ |

> `⌘K` / `Ctrl+K` ยังเป็นคีย์ลัด "โฟกัสแถบที่อยู่" ของ Chrome อีกด้วย เบราว์เซอร์อาจดักจับคีย์นี้ เว้นแต่โฟกัสจะอยู่ในช่อง input แบบข้อความ

## หน้ารายละเอียดเซสชัน (`/session?id=...`)

### เลื่อนหน้า (สไตล์ vim)

คีย์ลัดเหล่านี้ทำงานได้ทั้งบนหน้าอินเด็กซ์และหน้าเซสชัน เมื่อโฟกัส **ไม่** อยู่ในช่อง input, textarea หรือ contenteditable element

| คีย์ลัด | การกระทำ |
|----------|--------|
| `j` | เลื่อนลง 300px |
| `k` | เลื่อนขึ้น 300px |
| `g g` | เลื่อนขึ้นไปที่ด้านบนของหน้า |
| `G` (Shift+G) | เลื่อนลงไปด้านล่างของหน้า |
| `I` (Shift+I) | โฟกัสไปที่ textarea ของตัวเขียนบทสนทนา (chat composer) |
| `Escape` | ปลดโฟกัสจากช่อง input ที่กำลังใช้งาน เพื่อให้อนุญาตการเลื่อนด้วย j/k ทำงานได้ |

### แถบด้านข้างและการนำทาง

| คีย์ลัด | บริบท | การกระทำ |
|----------|---------|--------|
| `⌘B` / `Ctrl+B` | ระดับหน้า | สลับการแสดงผลของแถบด้านข้าง |
| `⌘K` / `Ctrl+K` | ระดับหน้า | เปิดพาเลตรายการเซสชัน |
| `⌘T` / `Ctrl+T` | ระดับหน้า | เซสชันใหม่ |
| `⌘⇧L` / `Ctrl+Shift+L` | ระดับหน้า | สลับธีมระบบ (สว่าง/มืด) |
| `⌘⇧N` / `Ctrl+Shift+N` | ระดับหน้า | สลับแถบด้านข้าง scratchpad / หมายเหตุ |

> `⌘K` และ `⌘T` ยังเป็นคีย์ลัดของเบราว์เซอร์ (โฟกัสแถบที่อยู่ / แท็บใหม่) อีกด้วย เบราว์เซอร์อาจดักจับคีย์เหล่านี้ เว้นแต่โฟกัสจะอยู่ในช่อง input แบบข้อความ

### ตัวเขียนบทสนทนา (Chat composer)

| คีย์ลัด | บริบท | การกระทำ |
|----------|---------|--------|
| `Enter` | textarea ของบทสนทนา | ส่งข้อความ |
| `Shift+Enter` | textarea ของบทสนทนา | แทรกบรรทัดใหม่ |
| `Shift+Tab` | textarea ของบทสนทนา | สลับไปยังระดับการคิดถัดไป (`off` → `minimal` → … → `xhigh` → `off`) |
| `Ctrl+I` / `Ctrl+L` | textarea ของบทสนทนา | เปิดป๊อปอัพเลือกโมเดล (พิมพ์เพื่อกรอง, Enter เพื่อกำหนด, โฟกัสจะกลับไปที่ textarea) |

### ตัวสลับการแสดงผลของรายการ

| คีย์ลัด | บริบท | การกระทำ |
|----------|---------|--------|
| `t` | เมื่อโฟกัส **ไม่** อยู่ในช่อง input/textarea | สลับการแสดงผลของส่วนคิด (thinking) |
| `o` | เมื่อโฟกัส **ไม่** อยู่ในช่อง input/textarea | สลับการแสดงผลของเครื่องมือ (tools) |
| `p` | เมื่อโฟกัส **ไม่** อยู่ในช่อง input/textarea | สลับการแสดงผลของผลลัพธ์เครื่องมือ |

### พาเลต เมนู และชีต

| คีย์ลัด | บริบท | การกระทำ |
|----------|---------|--------|
| `Escape` | ระดับหน้า | ปิดพาเลต เมนู หรือชีตที่เปิดอยู่ |
| `⌘K` / `Ctrl+K` | ระดับหน้า | เปิดพาเลตรายการเซสชัน |
| `ArrowUp` / `ArrowDown` | พาเลตรายการเซสชัน | นำทางผลการค้นหาเซสชัน |
| `Enter` | พาเลตรายการเซสชัน | เปิดเซสชันที่ถูกเลือก (หรือเซสชันแรก) |
| `ArrowUp` / `ArrowDown` | ป๊อปอัพเลือกโมเดล | นำทางรายการโมเดล |
| `Enter` | ป๊อปอัพเลือกโมเดล | เลือกโมเดลที่ถูกไฮไลต์ |
| `ArrowUp` / `ArrowDown` | โมดัล Fork | นำทางข้อความ |
| `Enter` | โมดัล Fork | สร้างสาขา (Fork) จากข้อความที่ถูกไฮไลต์ |
| `Tab` | ชีตแบบเต็มจอ | สลับโฟกัสภายในชีต |
| `Escape` | ชีตแบบเต็มจอ | ปิดชีต |
