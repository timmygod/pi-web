# pi-web ในฐานะผู้ช่วยส่วนตัวของคุณ

Workflow นี้รองรับโดย local-model edition สำหรับนโยบายการพัฒนา การซิงโครไนซ์ และการ release ของ edition ดังกล่าว ดูที่ [Local-model edition development](../../docs/dev/local-llm-development.md)

pi-web ไม่ได้ใช้สำหรับการเขียนโค้ดเท่านั้น — คุณสามารถเปลี่ยนมันให้เป็น **ผู้ช่วย AI ส่วนตัว** ที่อยู่บนคอมพิวเตอร์ของคุณ เปรียบเสมือนมี OpenClaw หรือ Hermes เป็นของตัวเอง

## วิธีทำงาน

คุณสร้างโฟลเดอร์เฉพาะบนเครื่องของคุณ — ที่นั่นคือที่ที่ผู้ช่วยของคุณอาศัยอยู่ ภายในนั้นคุณวางไฟล์ `APPEND_SYSTEM.md` ที่กำหนดว่าผู้ช่วยของคุณคือใคร รู้จักอะไร และทำงานอย่างไร pi-web ให้คุณด้วย interface การแชทที่สวยงามเพื่อพูดคุยกับมันได้จากทุกอุปกรณ์

## ทีละขั้นตอน

### 1. สร้างโฟลเดอร์ผู้ช่วยของคุณ

เลือกโฟลเดอร์บนคอมพิวเตอร์ของคุณ เช่น:

```
~/my-assistant/
```

### 2. กำหนดผู้ช่วยของคุณ

สร้างไฟล์ `APPEND_SYSTEM.md` ภายในโฟลเดอร์นั้น นี่คือที่ที่คุณบอก pi ว่าผู้ช่วยของคุณคือใคร:

```markdown
# My Personal Assistant

You are Jarvis, my personal AI assistant. You help me with:

- Daily planning and reminders
- Research and summarization
- Drafting emails and messages
- Brainstorming ideas
- Keeping track of things I mention

## About me

- I'm a software engineer who works remotely
- I have a cat named Pixel
- I prefer short, direct answers
- My timezone is PST

## Rules

- Be concise — I value brevity
- If you don't know something, say so
- Proactively remind me of things I asked you to track
```

pi จะเติม (append) ไฟล์นี้เข้าไปใน system prompt ของทุกการสนทนาโดยอัตโนมัติ ดังนั้นผู้ช่วยของคุณจึงรู้ว่า你是谁และจะช่วยอย่างไรอยู่เสมอ

### 3. เริ่มต้นเซสชันในโฟลเดอร์นั้น

ใน pi-web ให้สร้างเซสชันใหม่โดยชี้ไปที่ `~/my-assistant/` (หรือชื่อที่คุณตั้งไว้) แค่นั้น — คุณกำลังคุยกับผู้ช่วยส่วนตัวของคุณแล้ว

### 4. ใช้ได้จากทุกที่

ติดตั้ง pi-web เป็น PWA บนโทรศัพท์ แท็บเล็ต หรือแล็ปท็อปของคุณ ผู้ช่วยของคุณจะอยู่ที่นั่นเสมอ — ถามอะไรก็ได้ ทุกเวลา

## ไอเดียสำหรับผู้ช่วยของคุณ

| บทบาท | สิ่งที่ใส่ใน APPEND_SYSTEM.md |
|---|---|
| 🧠 **Life coach** | เป้าหมายของคุณ, ความเคยชินที่คุณกำลังฝึก, คำถามกระตุ้นให้บันทึกประจำวัน |
| 🏠 **Home manager** | รูปแบบรายการของใช้, ความชอบของสมาชิกในครอบครัว, การวางแผนอาหาร |
| 💼 **Work buddy** | บทบาทของคุณ, โปรเจกต์ปัจจุบัน, รูปแบบโน้ตการประชุม, บริบทขององค์กร |
| 📚 **Study partner** | สิ่งที่คุณกำลังเรียนรู้, สไตล์การอธิบายที่ชื่นชอบ, โหมดสอบถามคุณ |
| ✍️ **Writing assistant** | สไตล์การเขียนของคุณ, ความชอบด้าน tone, รูปแบบที่ใช้งานบ่อย |

## เพิ่ม context เพิ่มเติม

คุณสามารถใส่ทุกอย่างในโฟลเดอร์ผู้ช่วยของคุณที่ทำให้ pi มีประโยชน์มากขึ้น:

- `notes/` — ไฟล์อ้างอิงที่ผู้ช่วยของคุณสามารถอ่านได้
- `context.md` — ข้อมูลพื้นหลังเกี่ยวกับชีวิตหรืองานของคุณ
- `projects.md` — โปรเจกต์ปัจจุบันและสถานะของพวกมัน

pi สามารถอ่านไฟล์ในโฟลเดอร์ได้ ดังนั้น context ที่คุณให้越多 มันก็ยิ่งดีขึ้น

## ให้ pi-web ทำสิ่งต่าง ๆ

หลังจาก `pi install npm:@timmygod/pi-web-local` แล้ว เซสชันสามารถคุยกับตัว pi-web เองได้ ลอง:

- "เพิ่ม schedule ที่ 2 น. เวลาสิงคโปร์เพื่อสรุป inbox ของฉัน"
- "จัดรายการ schedule ของ pi-web ของฉัน"
- "พัก schedule inbox"
- "จดสิ่งนี้ไว้ใน notes"
- "สลับ pi-web เป็น dark mode / ปิด auto-title"

skill **/skill:pi-web-schedule** ที่ถูกบรรจุมา จะเปลี่ยนสิ่งนั้นให้เป็น schedule ของ pi-web ที่ใช้งานจริง (ตัวเดียวกันที่คุณแก้ไขที่ `/schedules`) แต่ละครั้งที่ fire จะเริ่มต้นเซสชัน **ใหม่** ดังนั้นคำสั่งต้องยืนได้ด้วยตัวเอง — "สรุปอีเมลที่ไม่ได้อ่านใน ~/inbox" ใช้งานได้; "ทำต่อจากที่เราทำอยู่" ใช้ไม่ได้

Schedule ทำงานได้เฉพาะตอนที่ pi-web ทำงานอยู่เท่านั้น

---

> 💡 **Tip:** เริ่มต้นแบบง่าย ๆ แค่ไม่กี่บรรทัดเกี่ยวกับว่าคุณเป็นใครและต้องการให้พฤติกรรมของผู้ช่วยเป็นอย่างไร ปรับแต่งไปตามเวลาเมื่อคุณเรียนรู้ว่าอะไรใช้ได้
