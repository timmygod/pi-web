**正在考虑试试 pi-web？那就来吧 — 你会爱上它的。**

pi-web 是为 [pi](https://pi.dev) —— 开源 AI 编程智能体 —— 打造的美观 Web UI 和 PWA。它让你可以在任何浏览器、任何设备上浏览、阅读并继续你的 pi 会话，处处都有贴心的功能。

## 这个版本有什么不同？

本仓库保留了上游 pi-web 的界面和共享功能，但当所选模型在本地或你的局域网（LAN）上运行时，改进了会话的保护方式。

- **按会话选择运行时策略。** 当 provider 元数据明确时，自动检测本地/LAN 端点；Local 和 Cloud 是持久的手动覆盖选项。
- **尽早防止上下文失败。** Local Mode 在用量达到 65% 时进行压缩，并在工具调用之间、下一次模型请求之前再次检查。
- **让摘要保持有界。** 滚动检查点避免让旧摘要无限膨胀，用更紧的预算重试一次，并在压缩没有取得有意义的进展时安全停止。
- **保守地恢复。** 上下文溢出、所选传输的中断以及仅推理导致的过早停止可以自动恢复，但事件去重和感知进展的断路器可以防止恢复循环。
- **让用户保持控制权。** Force Compact 始终是对用户可见的手动救援路径，而 Cloud Mode 保留上游的工作流和控制。

实际效果很简单：一个长时的本地模型任务应当在崩溃之前先进行压缩，在恢复安全时恢复一次，在恢复不安全时干净地停止而不是陷入循环。

**pi-web 为两类人打造：**

- 🧑‍💻 **面向开发者** —— 他们生活在终端中，但希望从移动设备继续会话、交接给远程服务器，或从任何地方监控长时间运行的任务。
- ✨ **面向非开发者** —— 他们只想要一个能用且美观的 AI 应用。打开它，输入内容，开始 vibe。没有终端，没有 SSH，没有困惑。就像最用户友好的 AI 工具，但可以选择模型，并拥有开源的自由。

## 为什么选择 pi-web？

你已经在终端中用 pi 进入深度心流状态了。当你离开书桌时，pi-web 让这股势头延续下去：

- **从任何地方恢复** —— 从你的手机、平板或另一台电脑继续会话。无需 SSH，无需 Termius —— 只需打开浏览器。
- **多会话仪表盘** —— 在一个会话中启动工作，同时观看另一个会话的流式输出。跨项目搜索、按分支过滤，快速找到你需要的内容。
- **开源基础** —— pi 完全开源且不绑定 provider。你不会被困在单一模型或厂商上。pi-web 也是开源的。
- **安全的远程访问** —— 内置 token 认证，让你可以放心地在局域网或 Tailscale 上暴露它。
- **分享你的工作** —— 一键将会话导出为静态快照或私密的 GitHub Gist。

## pi-web 作为你的个人 AI 工作空间 🏠

pi-web 是一个 PWA（渐进式 Web 应用），因此你可以**像原生应用一样安装它**在你的桌面、笔记本、手机或平板上 —— 无需应用商店。在桌面上它会以自己的窗口打开，没有浏览器边框，看起来和用起来就像一个真正的桌面应用。

把它想象成**你自己的 Claude Cowork** —— 一个生活在你的机器上的个人 AI 工作空间 —— 只不过是开源且不绑定模型的：

- **你拥有整个技术栈。** 选择任何模型，随时切换。运行一个本地模型，你的数据永远不会离开你的机器。
- **非技术人员也能使用它。** 在他们的机器上设置好 pi-web，教他们使用一次，他们就上手了。你的父母、你的伴侣、你的不懂技术的朋友 —— 没有终端，没有 SSH，只有一个熟悉的聊天界面。
- **一套设置，多个用户。** 安装在你的桌面上并共享你的屏幕，或者把它暴露在你的家庭网络上，让家人在他们自己的设备上打开。

想要超越编程吗？把它变成一个专门的[个人助理](personal-assistant.md)，它了解你是谁并生活在你的机器上 —— 就像你自己的 OpenClaw 或 Hermes。

> 💡 **小贴士：** 从 Chrome/Edge（点击地址栏中的安装图标）或 Safari（分享 → 添加到 Dock）安装 pi-web 作为 PWA。它将变得与原生应用无异。

## 你可以用 pi-web 做什么

| | |
|---|---|
| 📱 **PWA** | 将 pi-web 作为渐进式 Web 应用安装在桌面、手机或平板上，获得原生体验。 |
| 🔄 **继续会话** | 从你上次停下的地方接手任何对话 —— 文本、图像、模型切换，全部在浏览器中完成。 |
| 🆕 **开始新会话** | 直接在 Web UI 中针对任何项目路径创建新会话。 |
| 📡 **实时流式传输** | 实时观看 pi 的响应以约毫秒级延迟流式输出。跟随模式让你始终锁定在最新内容上。 |
| 🌲 **树视图** | 导航 pi 原生的消息树 —— 查看完整的对话结构，跳转到任何分支，并从任何点分叉。 |
| 🔀 **分叉会话** | 从任何消息甚至某个具体的工具调用分叉会话 —— 探索不同方向而不丢失你的位置。 |
| 🔍 **浏览与搜索** | 跨项目过滤会话，按名称搜索，导航分支 —— 一眼看清你的完整会话历史。 |
| 🌿 **Git 集成** | 查看当前分支，并直接从会话查看器打开一个 GitHub PR。 |
| 📝 **草稿本** | 在会话旁边记下笔记、待办事项或临时想法，无需切换应用。 |
| 💬 **批注** | 高亮并评论会话的任何部分 —— 非常适合代码审查、反馈或标记关键时刻。 |
| 🎨 **主题与自定义** | 在深色和浅色模式之间切换，按喜好调整 UI —— 让 pi-web 感觉像*你的*。 |
| 🌐 **多语言** | 14 种内置语言（English, Español, Français, Deutsch, 中文, 日本語, Bahasa Indonesia, Bahasa Melayu, Tiếng Việt, ไทย, Filipino, မြန်မာ, ភាសាខ្មែរ, ລາວ）。从设置中添加你自己的自定义语言。 |
| 🐱 **健康与 pomodoro** | 过多的 vibe coding 不健康。内置 pomodoro 计时器，配有猫咪伙伴和睡眠提醒，帮你保持平衡。 |
| 📤 **分享与导出** | 下载 JSONL，导出用 pi 原生 `pi.dev` 外观渲染的静态快照，或作为私密的 GitHub Gist 分享 —— 全部在客户端渲染。 |
| 🔔 **通知声音** | 可自定义的会话事件通知提示音 —— 即使 pi-web 在另一个标签页，也能保持跟进。 |
| ⌨️ **键盘快捷键** | Vim 风格的导航，快速操作 —— [完整参考 →](keyboard-shortcuts.md) |
| 🤖 **个人助理** | 将 pi-web 变成你自己的、生活在你的电脑上的 AI 助理 —— 就像 OpenClaw 或 Hermes。[设置它 →](personal-assistant.md) |
| 🗓️ **对话安排日程** | 在一个 pi 会话中，说“在新加坡时间凌晨 2 点添加一个日程……” —— `/skill:pi-web-schedule`。 |
| 📝 **对话操作笔记与设置** | “把这个写进笔记”（`/skill:pi-web-notes`）或“切换到深色模式”（`/skill:pi-web-settings`）。 |
