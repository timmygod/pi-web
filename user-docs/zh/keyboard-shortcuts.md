# 键盘快捷键

这些快捷键适用于 pi-web 的本地模型版本。与特定版本相关的
运行时行为在[本地模型版本开发](../../docs/dev/local-llm-development.md)中有说明。

## 索引页（`/`）

### 页面滚动（vim 风格）

当焦点**不在** input、textarea 或 contenteditable 元素中时，所有页面都可以使用相同的 vim 风格快捷键。

| 快捷键 | 操作 |
|----------|--------|
| `j` | 向下滚动 300px |
| `k` | 向上滚动 300px |
| `g g` | 滚动到页面顶部 |
| `G`（Shift+G） | 滚动到页面底部 |
| `Escape` | 使当前激活的输入框失焦，以便 j/k 导航生效 |

### 索引命令

| 快捷键 | 上下文 | 操作 |
|----------|---------|--------|
| `⌘K` / `Ctrl+K` | 页面级别 | 打开搜索/会话面板 |
| `⌘⇧L` / `Ctrl+Shift+L` | 页面级别 | 切换系统主题（浅色/深色） |
| `Escape` | 页面级别 | 关闭面板、菜单或模态框 |
| `Enter` | 新建会话路径输入框 | 创建新会话 |

> `⌘K` / `Ctrl+K` 同时也是 Chrome 的"聚焦地址栏"快捷键。除非焦点位于文本输入框内，否则浏览器可能会拦截该快捷键。

## 会话详情页（`/session?id=...`）

### 页面滚动（vim 风格）

当焦点**不在** input、textarea 或 contenteditable 元素中时，以下快捷键在索引页和会话页均可使用。

| 快捷键 | 操作 |
|----------|--------|
| `j` | 向下滚动 300px |
| `k` | 向上滚动 300px |
| `g g` | 滚动到页面顶部 |
| `G`（Shift+G） | 滚动到页面底部 |
| `I`（Shift+I） | 聚焦聊天输入框 textarea |
| `Escape` | 使当前激活的输入框失焦，以便 j/k 导航生效 |

### 侧边栏与导航

| 快捷键 | 上下文 | 操作 |
|----------|---------|--------|
| `⌘B` / `Ctrl+B` | 页面级别 | 切换侧边栏显示 |
| `⌘K` / `Ctrl+K` | 页面级别 | 打开会话列表面板 |
| `⌘T` / `Ctrl+T` | 页面级别 | 新建会话 |
| `⌘⇧L` / `Ctrl+Shift+L` | 页面级别 | 切换系统主题（浅色/深色） |
| `⌘⇧N` / `Ctrl+Shift+N` | 页面级别 | 切换草稿本/笔记侧边栏 |

> `⌘K` 和 `⌘T` 同时也是浏览器快捷键（聚焦地址栏 / 新建标签页）。除非焦点位于文本输入框内，否则浏览器可能会拦截这些快捷键。

### 聊天输入框

| 快捷键 | 上下文 | 操作 |
|----------|---------|--------|
| `Enter` | 聊天 textarea | 发送消息 |
| `Shift+Enter` | 聊天 textarea | 插入换行 |
| `Shift+Tab` | 聊天 textarea | 循环切换到下一个思考级别（`off` → `minimal` → … → `xhigh` → `off`） |
| `Ctrl+I` / `Ctrl+L` | 聊天 textarea | 打开模型选择器弹窗（输入以过滤，Enter 以选择，焦点返回 textarea） |

### 条目可见性切换

| 快捷键 | 上下文 | 操作 |
|----------|---------|--------|
| `t` | 当焦点**不在** input/textarea 中时 | 切换思考内容可见性 |
| `o` | 当焦点**不在** input/textarea 中时 | 切换工具可见性 |
| `p` | 当焦点**不在** input/textarea 中时 | 切换工具输出 |

### 面板、菜单与 sheet

| 快捷键 | 上下文 | 操作 |
|----------|---------|--------|
| `Escape` | 页面级别 | 关闭任何已打开的面板、菜单或 sheet |
| `⌘K` / `Ctrl+K` | 页面级别 | 打开会话列表面板 |
| `ArrowUp` / `ArrowDown` | 会话列表面板 | 在会话结果中导航 |
| `Enter` | 会话列表面板 | 打开选中的（或第一个）会话 |
| `ArrowUp` / `ArrowDown` | 模型选择器弹窗 | 在模型列表中导航 |
| `Enter` | 模型选择器弹窗 | 选择高亮的模型 |
| `ArrowUp` / `ArrowDown` | Fork 模态框 | 在消息中导航 |
| `Enter` | Fork 模态框 | 从高亮的消息处 Fork |
| `Tab` | 全屏 sheet | 在 sheet 内循环切换焦点 |
| `Escape` | 全屏 sheet | 关闭 sheet |
